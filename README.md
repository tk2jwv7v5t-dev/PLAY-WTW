# PLAY-WTW — غُرَف

My website is a place where you gather with your friends in a room, show them your screen, write to them and talk with them.

موقع رومات: تسوي روم، ترسل الرابط لخويك، وتسولفون بالصوت والشات وتبثون الشاشة.

## المميزات
- مكالمة صوتية جماعية (كتم المايك، كتم الصوت، مستوى صوت لكل شخص، مؤشر مين يتكلم)
- شات مباشر مع سجل الرسايل للي يدخل متأخر ومؤشر "يكتب…"
- بث الشاشة لين **4K** وبين **15 و144 فريم**، مع بت ريت تلقائي أو يدوي حسب نتك
- إحصائيات البث الحقيقية (الدقة، الفريمات، الميقابت، البنق)
- رومات عامة تبين كم واحد فيها، ورومات خاصة برابط دعوة
- بدون تسجيل وبدون سيرفر خاص: الاتصال مباشر بين الأجهزة (WebRTC عبر PeerJS)

## الملفات
- `index.html` — الصفحة
- `style.css` — التصميم الزجاجي
- `app.js` — منطق الرومات والصوت والشات والبث

## ملاحظات
- بث الشاشة يشتغل على كروم / إيدج / فايرفوكس في الكمبيوتر. الجوال يقدر يسمع ويكتب ويتفرج.
- كل مشاهد ياخذ نسخة من البث، فسرعة الرفع المطلوبة = البت ريت × عدد المشاهدين.
- لو فيه شبكات ما تتصل ببعض، أضف سيرفر TURN في `PEER_OPTS` داخل `app.js`.
